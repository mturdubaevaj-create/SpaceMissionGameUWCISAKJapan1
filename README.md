## The idea
Space missions succeed or fail on the trade-offs engineers make before launch: how much fuel, how powerful an engine, how heavy a payload. Space Mission Simulator puts players in that role. They design their own spacecraft and fly it on a mission, discovering through play how real physics like thrust, mass, and gravity decides whether they reach their destination. Built in Python/Pygame by team UWC ISAK-1, it makes learning how space missions work hands-on rather than something you only read about.
## What you can do
- Design your own spacecraft 
- Launch and fly missions 
- See how real physics decides whether your mission succeeds or fails

## 🚀 How to Play

### 1. Install Python
Download Python 3.8 or newer from [python.org](https://www.python.org/downloads/).
**Windows:** tick **"Add Python to PATH"** during installation.

### 2. Download the game
- **Easy way:** click the green **Code** button above → **Download ZIP** → unzip it.
- **With Git:**
  ```
  git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
  ```

### 3. Open a terminal in the game folder
- **Mac:** right-click the folder → **New Terminal at Folder**
  (or open Terminal, type `cd `, drag the folder in, press Enter)
- **Windows:** open the folder, click the address bar, type `cmd`, press Enter

### 4. Install pygame (first time only)
| Mac | Windows |
|---|---|
| `python3 -m pip install pygame` | `py -m pip install pygame` |

### 5. Run the game
| Mac | Windows |
|---|---|
| `python3 main.py` | `py main.py` |

The first launch takes a moment while the 8-bit music is generated.

### 🎮 Controls
- **Mouse:** menus and building your ship
- **Arrow keys / WASD + SPACE:** mini-games (landing, asteroids, rover)
- **SPACE / ENTER:** continue dialogue
- **F11:** fullscreen

### ❓ Problems?
- `command not found` / `not recognized` → Python isn't installed or isn't on PATH (see step 1).
- `No module named pygame` → repeat step 4.

Start with the **Moon tutorial** - Mission Control will guide you! 🌕
