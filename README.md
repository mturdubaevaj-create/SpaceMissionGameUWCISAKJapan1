## The idea
Space missions succeed or fail on the trade-offs engineers make before launch: how much fuel, how powerful an engine, how heavy a payload. Space Mission Simulator puts players in that role. They design their own spacecraft and fly it on a mission, discovering through play how real physics like thrust, mass, and gravity decides whether they reach their destination. Built in Python/Pygame by team UWC ISAK-1, it makes learning how space missions work hands-on rather than something you only read about.
## What you can do
- Design your own spacecraft 
- Launch and fly missions 
- See how real physics decides whether your mission succeeds or fails

## How to run
1. Install Python 3.10 or newer
2. Install the libraries: `pip install -r requirements.txt`
3. Start the game: `python main.py`
